# 📱 微信小程序使用指南

《山货有话说》微信小程序版，与电脑端网页共用同一个 FastAPI 后端（`backend/`），功能全覆盖：拍照识图、四件套生成、语音讲解、生成历史、多模型切换。

## 一、准备（约 5 分钟）

1. **启动后端**：双击项目根目录 `启动.bat`（保持窗口开着）
2. **安装微信开发者工具**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html （选"稳定版"）
3. 无需注册小程序账号——项目默认使用**游客模式**（`touristappid`），打开即可调试

## 二、导入项目

1. 打开微信开发者工具 → 「导入项目」
2. 目录选择：`D:\比赛2\miniprogram`
3. AppID 选择「**测试号**」或保持 `touristappid`（正式发布时再换成自己的 AppID）
4. 点击确定，模拟器里即可看到登录界面 → 注册一个账号 → 进入主应用

> **域名设置**：`project.config.json` 里已默认 `"urlCheck": false`（不校验合法域名）。
> 如果请求失败，请在开发者工具右上角「详情 → 本地设置」确认勾选了「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。

## 三、真机预览（手机上体验）

1. 先查电脑局域网 IP：`Win+R` → `cmd` → `ipconfig` → 找 IPv4 地址（如 `192.168.1.100`）
2. 修改 `miniprogram/config.js`：
   ```js
   BASE_URL: 'http://192.168.1.100:8000'
   ```
3. 确认手机与电脑连**同一个 Wi-Fi**
4. 开发者工具点「预览」生成二维码，手机微信扫码
5. 手机上打开小程序后，**点右上角胶囊 → 开发调试**打开调试模式（真机上 http 请求需调试模式放行）

## 四、正式发布（需要小程序账号）

1. 注册：https://mp.weixin.qq.com （个人主体即可，免费）
2. 拿到 AppID 后替换 `project.config.json` 里的 `"appid"`
3. **上线前必须完成**：
   - 准备一个已备案的 HTTPS 域名指向后端（如 `https://api.xxx.cn`），改 `config.js` 的 `BASE_URL`
   - 在小程序管理后台「开发管理 → 服务器域名 → request/uploadFile/downloadFile 合法域名」添加该域名
   - 上传代码 → 提交审核 → 发布
4. 竞赛演示的替代方案：用**体验版**（上传代码后设为体验版，把评委加为体验成员扫码使用），或直接用开发者工具现场演示

## 五、目录结构

```
miniprogram/
├── app.js / app.json / app.wxss   # 全局（页面注册、tabBar、全局样式）
├── project.config.json            # 开发者工具配置（urlCheck 已关闭）
├── config.js                      # 后端地址（真机预览时改这里）
├── utils/api.js                   # 请求封装（自动携带令牌）
└── pages/
    ├── login/    # 登录/注册（门禁页，进入前必经）
    ├── index/    # 拍照→识别→四件套（文案/海报/语音/脚本）
    ├── guide/    # AI 数字讲解员（24 省区村落 + 问答）
    ├── history/  # 我的生成历史（缩略图/删除）
    └── mine/     # 个人中心（模型引擎切换/关于/退出）
```

## 六、常见问题

| 问题 | 解决 |
|---|---|
| 模拟器里请求失败 | 后端没启动（双击 `启动.bat`），或没勾选"不校验合法域名" |
| 真机预览请求失败 | `config.js` 里的 BASE_URL 没改成局域网 IP，或手机不在同一 Wi-Fi，或没打开调试模式 |
| 语音/海报保存失败 | 下载临时文件需要网络可达 + 相册权限，按提示授权即可 |
| 提示"登录已过期" | 令牌 7 天有效，过期重新登录即可；后端重启不影响令牌（存在 SQLite 里） |
