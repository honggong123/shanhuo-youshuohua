# 🚀 上线部署指南（微信小程序版）

> 目标：让正式版/体验版小程序能访问你的后端。小程序上线 = 三件事：
> ① 注册小程序账号拿 AppID → ② **后端部署到合法 HTTPS 域名**（关键路径）→ ③ 后台配置域名 + 提交审核/发体验版。

---

## 第 0 步：注册小程序账号（免费，10 分钟）

1. 打开 https://mp.weixin.qq.com → 立即注册 → 选「小程序」
2. 主体类型选 **个人**（免费、无需认证；学生作品够用。企业/个体户可开更多类目）
3. 注册完成后在「设置 → 基本设置」拿到 **AppID**，填入 `miniprogram/project.config.json` 的 `"appid"` 字段
4. 类目建议：**工具 → 信息查询/效率**（AI 内容生成工具最常通过的类目）

---

## 两条部署路线（二选一）

### 路线 B：微信云托管（⭐ 推荐给比赛——免备案，1~2 天搞定）

ICP 备案要 2~3 周，比赛前等不起。微信云托管直接托管容器，**不需要域名备案**，且与小程序天然互通。

1. 打开 https://cloud.weixin.qq.com → 开通云托管（按量付费，新用户有免费额度，本项目流量小，基本免单）
2. 「服务设置 → 新建服务」，选择「从 Dockerfile 构建」，上传项目里的 `deploy/Dockerfile`（按提示把代码推到绑定的 Git 仓库）
3. 在服务的「环境变量」里配置模型 Key（`DEEPSEEK_API_KEY=你的Key` 等），无需 .env 文件
4. 部署完成后，在「服务信息」拿到公网访问地址（形如 `https://xxx.ap-shanghai.run.tcloudbase.com`）
   - 若走小程序 `callContainer` 调用则完全免域名配置（需改造 `utils/api.js`，工作量约半小时，需要时我来改）
   - 若走普通 `wx.request`：把该域名加入小程序后台「开发管理 → 服务器域名 → request 合法域名」
5. 修改 `miniprogram/config.js` 的 `BASE_URL` 为上述地址
6. 重新「上传」代码

### 路线 A：云服务器 + 域名 + 备案（正统方案，适合长期运营）

| 步骤 | 内容 | 耗时 | 费用 |
|---|---|---|---|
| 1 | 买云服务器（腾讯云/阿里云轻量，2核2G 足够） | 即时 | ~50~100 元/年（学生优惠） |
| 2 | 买域名（.cn/.com 均可） | 即时 | ~50~80 元/年 |
| 3 | **ICP 备案**（在云厂商控制台提交，个人网站备案） | **1~3 周** | 免费 |
| 4 | 服务器上：安装 nginx + 免费证书，跑 `uvicorn`（systemd 常驻），参考 `deploy/nginx参考配置.conf` | 半天 | 0 |
| 5 | 小程序后台配置 request/downloadFile 合法域名 = `https://api.你的域名.cn` | 即时 | 0 |
| 6 | 改 `miniprogram/config.js` 的 `BASE_URL` → 重新上传代码 | 即时 | 0 |

## 提交审核 / 发体验版

1. 开发者工具点 **「上传」**，填版本号和备注
2. mp.weixin.qq.com 后台 →「版本管理」：
   - **体验版**：把刚上传的版本设为体验版 → 「成员管理」把评委的微信号加为体验成员 → 扫体验码使用（**体验版不审核，比赛演示推荐走这条路**）
   - **正式发布**：提交审核（通常 1~2 天）→ 通过后发布

⚠️ **AIGC 类审核提示**：AI 生成内容类小程序近年审核趋严，个人主体可能被要求补充说明。降低风险的三个做法：
- 类目选「工具」而不是「内容资讯」
- 首页/关于页保留现有声明："内容由 AI 生成，仅供参考"
- 被驳回时按驳回原因补充《功能说明》截图；实在过不了就以体验版参赛演示

## 上线前检查清单

- [ ] `miniprogram/config.js` 的 `BASE_URL` 已改为线上 HTTPS 地址
- [ ] `project.config.json` 的 `appid` 已替换为正式 AppID
- [ ] 小程序后台「服务器域名」已配置（request / uploadFile / downloadFile 三个都要）
- [ ] 后端 `.env` 里的 Key 已配置到云环境变量（**不要**把 .env 提交进仓库）
- [ ] 手机真机（非调试模式）实测：注册 → 登录 → 拍照 → 生成 → 播放全流程
- [ ] 关于页的 AI 内容声明、开源仓库链接可见
