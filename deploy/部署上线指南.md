# 🚀 上线部署指南（微信云托管版）

> 目标：让**体验版/正式版小程序**访问到你的后端。
> 三件事：① 拿到 AppID ✅ → ② **后端部署到云托管**（当前卡在这）→ ③ 小程序改地址 + 发体验版。

## 第 1 步：开通云托管环境

1. 打开**微信开发者工具** → 顶部「开发与服务」→「云服务」→ 点「开通」
   （或直接访问 <https://cloud.weixin.qq.com/cloudrun>）
2. 手机扫码确认，**环境类型选「云托管环境」，不要选「云开发环境」**（两者不通用）
3. 环境创建约 5 分钟

> ⚠️ 部分账号（尤其未认证的个人主体）开通时会要求先完成小程序认证，认证有费用且需 1~2 天审核。
> **如果卡在这一步**，说明是账号资质问题，不是代码问题——需要先完成认证，或改用路线 A。

---

## 第 2 步：新建服务 + 上传代码包

1. 云托管控制台 →「服务管理」→「新建服务」
2. 部署方式选 **「上传代码包」**（不要选「从 Git 仓库构建」，本项目用不上）
3. 上传 `deploy/backend_cloudrun.zip`

> 📦 **这个包已修复并验证过**。旧的包会构建失败：zip 里的 Dockerfile 只写了
> `COPY app/ ./app/`，却漏了 `COPY requirements.txt .`，pip 找不到依赖清单直接报
> `Could not open requirements file`。
> 以后改了后端代码，重新生成包只需跑：
> ```bash
> python deploy/build_cloudrun_zip.py
> ```

## 第 3 步：服务设置（关键，三项都要配）

| 项 | 值 | 说明 |
|---|---|---|
| **端口** | `80` | 保持默认。Dockerfile 用 `${PORT:-80}` 自适应，两边必须一致，否则部署失败 |
| **环境变量** | 见下 | 从本机 `backend/.env` 里把 5 个 Key 的值复制过来 |
| **公网访问** | 开启 | 先开着方便用 curl 测；只给小程序用时可以关 |

环境变量（**值从本机 `backend/.env` 复制，不要写进代码仓库**）：

> ⚠️ 本机 `backend/.env` 里目前**只有 `DEEPSEEK_API_KEY` 有值**，其余 4 个是空的。
> DeepSeek 不支持识图与生图，所以真实识图会走演示数据、海报走本地模板。
> 想拿到完整的真实 AI 能力且**零成本**，去 <https://open.bigmodel.cn> 申请免费的智谱 Key
> （`glm-4-flash` / `glm-4v-flash` / `cogview-3-flash` 三个模型全免费），填入 `GLM_API_KEY`，
> 并把 `DEFAULT_PROVIDER` 设为 `glm`。

```
GLM_API_KEY=<智谱 Key，免费，推荐>
DEEPSEEK_API_KEY=<本机已配>
QWEN_API_KEY=<空>
MOONSHOT_API_KEY=<空>
OPENAI_API_KEY=<空>
DEFAULT_PROVIDER=glm
TTS_VOICE=zh-CN-XiaoxiaoNeural
```

## 第 4 步：部署并验证后端真的活着

1. 点「部署」，盯**构建日志**，出现 `Successfully built` / `部署成功` 才算过
2. 在「服务详情」拿到公网域名（形如 `https://xxx-xxx.ap-shanghai.run.tcloudbase.com`）
3. **立刻用浏览器打开** `<域名>/api/health`

```
✅ 正确：{"ok":true,"demo":false}      ← demo:false 表示 Key 已生效
⚠️ demo:true                            ← Key 没配进去，回去检查环境变量
❌ 502 / 无法访问                       ← 看日志：多半是端口不一致（回第 3 步）
```

---

## 第 5 步：小程序连上后端

改 `miniprogram/config.js`：

```js
BASE_URL: 'https://你的云托管域名'   // 末尾不要带 /
```

然后在**微信开发者工具**里重新编译，模拟器应能正常注册登录、生成。

> **模拟器**能直接用；**真机**需要在手机上点右上角胶囊 →「开发调试」打开调试模式，
> 否则 http/域名校验会拦请求（见下面「坑位 D」）。

## ⚠️ 云托管的 5 个坑（按会遇到的顺序排）

### 坑 A：端口不一致 → 构建成功但部署失败
日志出现 `端口不匹配` / 服务反复重启。把控制台端口和 Dockerfile 的端口对齐（都 80）。

### 坑 B：容器可能访问不了外网
本项目的识图/文案/生图要调智谱、DeepSeek，语音要调 Edge-TTS，**都需要容器能主动出网**。
云托管「公网访问」管的是**入站**；**出站**在部分环境需要额外开 NAT 网关。
**怎么判断**：生成文案时报错/超时，但 `/api/health` 正常 → 就是出网被拦。
**兜底**：不影响演示——无 Key 时自动进演示模式（内置文案 + 本地模板海报）；
但 Edge-TTS 语音仍需联网，出网不通则语音不可用。

### 坑 C：请求体大小限制（已修复）
云托管限制：**文本请求 100 KiB，二进制 20 MiB，返回 1000 KiB，超时 60 秒**。

原来小程序把图片转 base64 塞进 JSON 发（走"文本"通道）。实测本机真实上传照片：

| 照片 | JSON 请求体 | 距 100 KiB 上限 |
|---|---|---|
| 75.8 KB | 101,132 B | 只剩 1.2 KiB |
| 76.3 KB | 101,788 B | 只剩 0.6 KiB |

等于靠"刚好压线"过关，照片稍大必挂。

**已改为**：小程序用 `wx.uploadFile` 走 multipart 二进制通道（20 MiB 额度）。
后端 `/api/recognize`、`/api/poster` 现在**同时接受** multipart 和旧的 JSON base64，网页端不受影响。

> ⚠️ 网页版（`frontend/`）仍走 base64 JSON，所以**把网页版也挂到云托管上会失败**；
> 网页版本地演示 / 自建服务器正常。需要网页版也上云时告诉我，改造量很小。

### 坑 D：默认公网域名不能配进小程序后台
官方明确：默认公网域名**仅可做测试之用，小程序后台无法配置**。
所以：**体验版 + 手机开「开发调试」可以用**；**正式版必须绑定已备案的自定义域名**。

> 比赛演示走「体验版」这条路即可：上传代码 → 设为体验版 → 把评委微信号加为体验成员 → 扫码。
> **体验版本身不需要审核。**

### 坑 E：数据是临时的（心里有数即可）
容器里的 `shanhuo.db`（用户账号/生成历史）、`uploads/`、`generated/` 都是**容器本地文件**，
重新部署/实例重建就会清空。演示前先注册好账号、跑通流程，**不要指望数据持久化**。

### 坑 F：海报中文变方块（已修复）
海报是 PIL 在服务端直接写字的，`python:3.12-slim` 镜像**不含中文字体**，
原代码又只找了 `C:\Windows\Fonts` → 云端生成的海报中文会全是方块。

**已修复**：镜像里装 `fonts-noto-cjk`，字体候选表补上 Linux/macOS 路径，
找不到字体时打警告日志（不再静默降级）。

## 路线 A：云服务器 + 备案域名（要正式长期运营时再走）

| 步骤 | 内容 | 耗时 | 费用 |
|---|---|---|---|
| 1 | 买云服务器（2核2G 够用） | 即时 | ~50~100 元/年（学生优惠） |
| 2 | 买域名（.cn/.com） | 即时 | ~50~80 元/年 |

| 4 | 装 nginx + 免费证书，`uvicorn` 常驻，参考 `deploy/nginx参考配置.conf` | 半天 | 0 |
| 5 | 小程序后台配 request/downloadFile 合法域名 | 即时 | 0 |
| 6 | 改 `miniprogram/config.js` 的 `BASE_URL` | 即时 | 0 |

> 云服务器上部署直接用**仓库根目录的 `Dockerfile`**（按 `backend/` 前缀写的）或 `python -m uvicorn` 裸跑。

## 提交审核 / 发体验版

1. 开发者工具点「上传」，填版本号和备注
2. mp.weixin.qq.com 后台 →「版本管理」：
   - **体验版**：设为体验版 →「成员管理」加评委微信号 → 扫码使用（**比赛演示推荐**）
   - **正式发布**：提交审核（1~2 天）→ 通过后发布

⚠️ AIGC 类审核趋严，个人主体可能被要求补充说明。降低风险：
- 类目选「工具」而非「内容资讯」
- 保留页面上的 AI 内容声明
- 实在过不了就以**体验版**参赛演示
