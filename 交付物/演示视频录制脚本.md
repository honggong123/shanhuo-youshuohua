# 🎬 演示视频录制脚本（对照执行即可，预计 10 分钟）

> **工具**：Windows 自带 `Win + G`（Xbox Game Bar）或 [OBS Studio](https://obsproject.com)（推荐）
> **参数**：1920×1080、16:9、MP4、≤5 分钟（竞赛硬性要求）
> **前置**：后端已启动（`cd backend && python run.py`），浏览器打开 <http://127.0.0.1:8000>，按 F11 全屏，缩放 100%
> **录音**：建议录完屏后配音（手机录＋剪映降噪即可），或直接用 TTS 音频铺底

---

## 开场（0:00 – 0:30）｜配口播

**画面**：停在首页 Hero 区，鼠标缓慢划过五个能力标签

> 口播：*"在山区，好山货卖不出好价钱，往往不是品质问题，而是没人会讲它的故事。《山货有话说》用 AI 让每一份山货开口说话——这是面向'乡村振兴·科创赋能'命题的参赛作品。"*

## 第一幕：上传与识别（0:30 – 1:15）

**操作**：
1. 鼠标移到上传区，点击选择照片（提前把真实产品照片放桌面）
2. 照片预览出现，停留 2 秒
3. 点击「🤖 开始 AI 识别」，结果出现后停留 3 秒，鼠标划过亮点标签

> 口播：*"农户只需拍一张照片，多模态大模型自动识别品种、产地和品质亮点，为山货建立数字档案。"*

## 第二幕：一键四件套（1:15 – 3:00）｜核心展示

**操作**：点击「✨ 一键生成四件套」，然后按顺序点开四个标签页，每个停留 5~8 秒：

| 顺序 | 标签页 | 展示重点 |
|---|---|---|
| 1 | ✍️ 卖点文案 | 鼠标划过卖点列表，最后停在乡土故事段落 |
| 2 | 🖼️ 文创海报 | 海报放大停留，点一下「下载海报」再取消 |
| 3 | 🔊 语音介绍 | **把音量调大**，让评委听到 TTS 语音效果 |
| 4 | 🎬 视频脚本 | 鼠标滚过分镜 1→4，停在带引导购买的最后分镜 |

> 口播：*"点击一次，四件套同时生成：电商卖点文案、AIGC 文创海报、方言味语音介绍、可直接开拍的短视频分镜脚本。从拍照到全套营销素材，不超过 30 秒。"*

## 第三幕：数字讲解员（3:00 – 4:00）

**操作**：
1. 滚动到「🧭 AI 数字讲解员」
2. 点击「袁家村」，再点「🎙️ 生成沉浸式讲解」
3. 讲解文字出现后停留 3 秒，**播放语音 8~10 秒**
4. 在提问框输入"这里有什么好吃的？"，点「提问」

> 口播：*"不只卖货，还要留客。AI 数字讲解员为村落生成沉浸式导游词，实时语音讲解，游客还能随时提问——把'过路客'变成'过夜客'。"*

## 结尾（4:00 – 4:30）

**操作**：滚动回顶部，停在 Hero 区

> 口播：*"识别、文案、海报、语音、脚本、讲解——全部基于开放大模型能力，零训练成本，任何县域都能直接使用。山货有话说，让乡村振兴的故事被更多人听见。谢谢观看。"*

---

## 录制注意事项

- [ ] 关闭微信/QQ 等通知弹窗，清理浏览器书签栏
- [ ] 浏览器缩放 100%（`Ctrl+0`），确保页面完整清晰
- [ ] 每次点击动作之间**放慢节奏**，给评委阅读时间
- [ ] 演示模式下页面会显示「演示数据」角标：正式录制前先把 API Key 填进 `backend/.env`，角标会变成「AI 已连接」
- [ ] 录完用剪映做：开头加 3 秒标题卡（作品名+赛道）、结尾加 5 秒团队信息卡、背景音乐音量 ≤ 口播的 20%
- [ ] 导出参数：**1080P / 16:9 / MP4 / ≤5 分钟 / ≤300M**
