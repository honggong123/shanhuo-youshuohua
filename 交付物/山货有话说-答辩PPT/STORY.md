# STORY.md · 《山货有话说》答辩演示叙事

## 一、这次答辩要回答的问题

评委听完后应能回答三件事：
1. **为什么做**——山区农产品与乡村文旅的真实痛点是什么？
2. **做成了什么**——一张照片进去，什么出来？技术上怎么实现的？
3. **有什么不一样**——凭什么是"作品"而不是"调用 API 的玩具"？

## 二、叙事主线

采用「**痛点 → 破题 → 实现 → 验证 → 价值**」的学术汇报逻辑，不堆功能清单，
每章回答一个递进问题，形成完整论证链。

```
痛点有多真  →  方案有多准  →  实现有多难  →  效果有多好  →  意义有多大
（问题定义）   （解决思路）   （技术攻坚）   （运行验证）   （社会价值）
```

## 五、内容取舍原则

**保留**（评委关心的）：
- 真实痛点与需求推导过程
- 架构设计的合理性论证
- 技术难点的解决思路（尤其海报中文方案）
- 可验证的实测数据
- 社会价值与应用前景

**压缩**（评委不关心的）：
- 代码实现细节、函数级说明
- 完整功能清单罗列
- 泛泛的"使用了 AI 技术"表述

**删除**：
- 说明书里的目录、致谢等文档性内容
- 未经验证的预期效果
