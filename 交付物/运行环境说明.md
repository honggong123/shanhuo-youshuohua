## 一、作品概况

**作品名称**：山货有话说 —— AI 助农数字文创平台

**作品形态**：微信小程序 + 网页版（共用同一后端服务）

**核心功能**：拍照识别农产品 → AI 生成营销文案 / 国潮海报 / 语音讲解 / 乡村导览

## 六、本地运行方式

### 方式一：一键启动（推荐）

```
双击项目根目录的  启动.bat
```
脚本会自动启动后端服务并打开浏览器访问 `http://127.0.0.1:8000`

### 方式二：手动启动

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 小程序端

1. 用微信开发者工具打开 `miniprogram/` 目录
2. 在 `miniprogram/config.js` 中配置后端地址 `BASE_URL`
3. 点击「编译」即可在模拟器中运行

## 八、注意事项

1. **API Key 安全**：提交包内**不包含** `backend/.env`（含真实密钥）。
   运行前请复制 `backend/.env.example` 为 `.env` 并填入自己的 Key。
2. **数据持久化**：云端容器内数据为临时存储，重新部署会清空。
3. **域名白名单**：云托管默认公网域名无法配置进小程序后台合法域名，
   真机调试需在微信中开启「开发调试」模式。
4. **中文字体**：容器内已安装 `fonts-noto-cjk`，本地 Windows 使用系统字体，无需额外配置。
